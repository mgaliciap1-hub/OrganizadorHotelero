DESCRIPCIÓN DEL PROYECTO:
El Sistema de Reservaciones de Hotel es una aplicación desarrollada en C++ por consola diseñada para administrar la infraestructura, clientes, reservaciones y reportes financieros de un hotel de manera eficiente.  El programa permite controlar el ciclo completo de una estadía (Check-in, consulta de disponibilidad, Check-out y cobro), manteniendo la información persistente mediante archivos de texto plano.

Comprensión del Problema
Problema que resolverá el sistema:
Actualmente, los establecimientos hoteleros pequeños y medianos suelen llevar el control de hospedaje de forma manual o descentralizada. Esto genera errores operativos graves como la sobreventa de habitaciones, lentitud en la atención al cliente durante el registro de entrada (Check-in) y salida (Check-out), pérdida de datos de clientes y la falta de visibilidad en tiempo real sobre la disponibilidad real de cuartos y el cálculo de ingresos acumulados. Este sistema resuelve dicha problemática unificando el control operativo en una plataforma lógica centralizada.  Público Objetivo (¿Quién podrá utilizarlo?): El sistema está diseñado para ser utilizado por el personal administrativo, recepcionistas y gerentes de establecimientos hoteleros encargados de la atención a clientes, asignación de habitaciones y administración de métricas financieras. 

Objetivo Principal: 
Definir, estructurar y desarrollar un sistema informático modular para la automatización integral del ciclo de hospedaje (administración de cuartos, registro de clientes, gestión de reservas/estadías y generación de reportes generales) con el fin de optimizar el tiempo de atención y garantizar la consistencia de la información.
